# Python Notebooks

This folder contains Python notebooks used for data cleaning, preprocessing, exploratory data analysis (EDA), and climate data analysis for the Live Climate and Extreme Weather Dashboard project.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Workflow
1. Load the raw climate datasets.
2. Inspect the data structure and identify missing values and duplicates.
3. Clean and transform the data.
4. Perform exploratory data analysis.
5. Prepare the cleaned datasets for visualization in Power BI.

## Files
Add your Jupyter Notebook (`.ipynb`) files to this folder.

## How to Run
Open the notebook using Jupyter Notebook or VS Code and run the cells in order.
